# Rox-Filer2-QT 1.0.7 — build and runtime dependencies

`./dependencies.sh` knows the differences between Debian/Devuan/Essora
(`apt-get`), Void (`xbps-install`) and Arch (`pacman`). Package managers vary:
run `./dependencies.sh --check` and confirm which optional packages exist in
your enabled repositories before attempting an installation.

## Compile (mandatory)

| Component | Debian / Devuan / Essora | Void Linux | Arch Linux |
| --- | --- | --- | --- |
| Compiler and tooling | `build-essential cmake ninja-build pkg-config` | `base-devel cmake ninja pkg-config` | `base-devel cmake ninja pkgconf` |
| Qt6 development | `qt6-base-dev qt6-base-dev-tools` | `qt6-base-devel` | `qt6-base` |
| Qt6 translations | `qt6-tools-dev-tools qt6-l10n-tools` | `qt6-tools qt6-tools-devel` | `qt6-tools` |

Qt6 **>= 6.4** with Core, Gui, Widgets, DBus and `lrelease` is required.
Qt SVG support is recommended (`libqt6svg6-dev`, `qt6-svg-devel`, `qt6-svg`).
The current Qt targets do **not** directly link to libmtp, gphoto2,
libimobiledevice, FUSE or libsmbclient.

## Additional headers and libraries (installed by `--install-build`)

| Stack | Debian / Devuan / Essora | Void Linux | Arch Linux |
| --- | --- | --- | --- |
| MTP / Android | `libmtp-dev` | `libmtp-devel` | `libmtp` |
| Cameras PTP | `libgphoto2-dev` | `libgphoto2-devel` | `libgphoto2` |
| iPhone / iPad | `libimobiledevice-dev` | `libimobiledevice-devel` | `libimobiledevice` |
| Samba client API | `libsmbclient-dev` | `samba-devel` | `smbclient` |
| FUSE 3 | `libfuse3-dev` | `fuse3-devel` | `fuse3` |
| FUSE 2 | `libfuse-dev` | `fuse-devel` | `fuse2` |
| USB / plist | `libusb-1.0-0-dev`, `libplist-dev`, `libusbmuxd-dev` | `libusb-devel`, `libplist-devel`, `libusbmuxd-devel` | `libusb`, `libplist`, `libusbmuxd` |

Additional metadata/desktop development libraries are included as optional
packages (`glib`, `libudev`, `libarchive`, `libmagic/file`, `dbus`). Libraries
absent in the configured repositories are **reported** rather than installed
under a guessed alternate name. Install missing optional packages manually
if your particular application needs them.

## Runtime / device support

The base runtime installation contains **udisks2, D-Bus, Polkit**, `pkexec`,
`util-linux`, `shared-mime-info`, `xdg-utils`, and desktop entry utilities.
A graphical Polkit authentication agent is necessary when a privileged
operation requests one. On Void these services must be configured with the
system's init/session facilities as usual; a build does not require systemd.

`--install-runtime` also attempts the following optional toolsets, using
package names native to the distro:

- Samba / CIFS: `samba`, `smbclient` when packaged separately, `cifs-utils`.
- ISO and filesystem tools: `fuse`/`fuse3`, `squashfs-tools`, `squashfuse`,
  `eject`, `exfatprogs`, `ntfs-3g`.
- Android: `libmtp`, `jmtpfs`, `simple-mtpfs`, optional GVfs stack.
- Cameras: `gphoto2`, `gphotofs`.
- iPhone: `ifuse`, `libimobiledevice`, `usbmuxd`.
- Thumbnails / codecs: Qt image formats, `ffmpegthumbnailer`, Poppler tools.
- Other desktop integrations: Avahi, optional Qt Wayland plugins.

**Scope clarification:** full mobile-device integration (MTP/PTP/iOS) is not
yet implemented in this standalone Qt frontend. Installing development
headers or external commands does not by itself implement these features.
GVfs is **not** a required build dependency and no broad Polkit bypass rules
are added.

## Commands

```bash
./dependencies.sh --check
# as root:
./dependencies.sh --install-build
./dependencies.sh --install-runtime
# or both in one command:
./dependencies.sh --install-full
# as a regular user:
./build-void.sh       # Void: system Qt6; no DEB
QT_MODE=system ./build.sh  # all supported distros, system Qt6
QT_MODE=essora ./build.sh  # opt-in private Essora Qt6
```

A native Void `.xbps` package is **not** generated by `build-void.sh`.
`cmake --install build-qt` can install the compiled application as root; distro
packagers should prefer a DESTDIR-based package build.
